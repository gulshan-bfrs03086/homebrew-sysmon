# homebrew-sysmon

Homebrew tap for [sysmon](https://github.com/gulshan-bfrs03086/sysmon) — a
real-time system monitor for macOS and Linux.

```bash
brew install gulshan-bfrs03086/sysmon/sysmon        # the terminal UI
brew install --cask gulshan-bfrs03086/sysmon/sysmon-app   # the desktop app (macOS)
```

Or tap once and use the short names:

```bash
brew tap gulshan-bfrs03086/sysmon
brew install sysmon
```

The contents of this repository are generated from a sysmon release by
`scripts/update-homebrew.sh` in the main repo — please do not edit the formula
by hand, or the next release will overwrite it.
